# SIMS Writer v3.4.0

## Personal Knowledge Separation

This MINOR release makes the standard Writer distribution tenant-neutral.

- Replaced tenant/blog-specific fixtures with synthetic site names, URLs, Article IDs, and Case IDs.
- Removed tenant-specific Operational Learning records from embedded Shared compatibility snapshots.
- Generalized the retained intent-drift pattern while preserving the reusable rule.
- Preserved Writer request/result contracts, treatment logic, and Shared v3.5.1 compatibility baseline.
- Deprecated external API integration remains removed.

No destructive migration of existing operational data is required.
