# SIMS Shared Editorial Knowledge v3.0.0

## Theme
Knowledge-driven editorial architecture with temporal lifecycle awareness.

## Added
- Temporal Search Intent and Content Lifecycle
- Evidence Confidence and Contradiction model
- Preservation Signals
- Learning promotion flow
- Shared Confidence, Source, Review, and Assembly policies
- Platform and Knowledge Set registries
- Temporal Lifecycle Recovery pattern and validation codes

## Compatibility
Writer receives mandatory v3 mapping. Article Creator v1.5.0 remains functionally compatible; only a later snapshot/reference update is required when adopting Shared v3 physically.
