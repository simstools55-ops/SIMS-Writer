# Content Lifecycle

## Lifecycle states
- ANNOUNCED: planned or officially announced, not yet active
- SCHEDULED: dated and expected to begin
- ACTIVE: currently available, distributed, sold, or usable
- COMPLETED: distribution or event is complete but use/support may continue
- EXPIRING: a confirmed deadline is approaching
- EXPIRED: the main action is no longer available
- ARCHIVED: retained mainly for historical/reference value
- UNKNOWN: evidence is insufficient

## Editorial response
A lifecycle transition does not automatically justify a full rewrite. Prefer fact updates, promise alignment, heading changes, Answer First updates, and outdated-call-to-action removal. Escalate scope only when the reader's primary task has materially changed.
