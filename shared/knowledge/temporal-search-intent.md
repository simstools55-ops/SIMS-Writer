# Temporal Search Intent

## Principle
Search intent can change as an event, campaign, product, law, service, or deadline moves through time. A currently accurate article can become misaligned even when its core subject remains unchanged.

## Required review
1. Identify the article's current lifecycle phase.
2. Compare future-tense, active-tense, completed-tense, and expired-tense claims.
3. Re-check the dominant user task for the current phase.
4. Preserve still-valid historical context and proven query entities.
5. Update only components whose promise or facts are no longer current.

## Typical transitions
- announcement -> eligibility / expected date
- distribution -> arrival / receipt
- active operation -> use / troubleshooting
- deadline approaching -> completion / expiration avoidance
- expired -> results / archive / successor information

Search demand is evidence of interest, not proof of a factual claim.
