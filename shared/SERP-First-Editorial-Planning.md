# SERP-first Editorial Planning

When a target page is not within the top three for its main query, inspect the current top results before deciding the editorial change scope. Use them to understand the search intent, expected answer form and material coverage—not as text or outline templates.

Compare the target article against:
- common intent-material coverage;
- important content present above but absent or weak in the target;
- useful original value present only in the target;
- accuracy, freshness and source-quality differences.

Only add a gap when it is relevant to the searcher's task and can be supported. Never manufacture findings from snippets or unavailable pages. If current SERP evidence is unavailable, disclose the limitation internally and do not approve competitor-gap-dependent edits.
