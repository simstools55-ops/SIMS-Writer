# Temporal Lifecycle Validation v3.0

Codes:
- CONTENT_STALE: one or more material claims are outdated
- TEMPORAL_SHIFT: dominant reader task changed with time
- LIFECYCLE_CHANGE: evidenced phase differs from article framing
- CONTENT_EXPIRED: primary action is no longer available
- CONTRADICTION_DETECTED: material article/source conflict remains

Pass conditions:
- current lifecycle phase is identified or UNKNOWN is explicit
- all material dates/deadlines use consistent scope
- planned/active/completed/expired wording matches evidence
- no unresolved contradiction is labeled PUBLIC_OK
- historical context is not erased without editorial need
