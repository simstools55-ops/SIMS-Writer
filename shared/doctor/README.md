# SIMS Doctor Shared Knowledge

Doctor, SBM, Writer, Creator, and future Merge implementations share the Case, Treatment, Referral, protection-boundary, and interface terminology defined here.

## Canonical platform documents

- `INTERFACE_CONTRACTS_V2.md`: SBM-centered routing and data ownership
- `CASE_LIFECYCLE_V1.md`: Case identifier and state lifecycle
- `CASE_TREATMENT_TERMINOLOGY.md`: shared terms and product roles
- `SBM_DOCTOR_SAFETY_BOUNDARY.md`: runtime and workflow safety boundaries

`INTERFACE_CONTRACTS_V1.md` remains only for compatibility with older Doctor-centered messages.

Doctor-specific numerical thresholds and collector implementation remain in the Doctor repository.
