# Reviewer Precision Rules v1.3.7

公開前品質確認は次を必須検出する。

1. LOW/MEDIUM Coverageで「大部分」「主因」「典型的」と断定しない。
2. 「増えている」「時代の新症状」など時系列主張は根拠なしで出さない。
3. 製品・機能と症状の因果を、本文根拠なしで結び付けない。
4. 別記事へ分離すると判断した意図を、FAQや見出しで再び本記事へ取り込まない。
5. 「正解」「必ず」「唯一」「完全解説」「5分で解決」は適用条件を確認し、必要なら緩和する。
6. `final_verdict=PASS`のときRequired Fixを残さない。
