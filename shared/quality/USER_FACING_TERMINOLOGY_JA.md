# 利用者向け用語表示方針 v1.0

利用者向け本文は日本語を基本とする。内部コード、JSON列挙値、検証ルールIDは機械処理互換のため英語を維持する。

## 表示規則

- 初出: `改善推奨（IMPROVEMENT_RECOMMENDED）`
- 2回目以降: `改善推奨`
- 見出し: `取得クエリの網羅率`（必要な場合のみ `Query Coverage` を初出併記）
- 診断: `掲載順位を生かしたクリック改善機会（POSITION_OPPORTUNITY）`
- 検索意図: `検索意図とのずれ（Intent Gap）`
- 公開前工程: `公開前品質確認（Publication QA）`

JSONではコード値を変更しない。必要に応じて `*_label_ja` を追加し、利用者向け表示は日本語ラベルを使う。

## 禁止

- 英語コードだけを説明なしで利用者向け本文へ連続表示する。
- 同じ段落で日本語と英語を何度も併記する。
- JSONの列挙値を日本語へ置き換えて連携互換を壊す。
