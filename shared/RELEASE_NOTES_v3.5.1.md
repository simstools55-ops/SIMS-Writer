# SIMS Shared Editorial Knowledge v3.5.1

## Writer Autonomous Decision Quality Hotfix

- Added User Decision Resolution Policy v3.5.1.
- `USER_DECISION` is now reserved for genuine owner-only facts, rights, contracts, irreversible site actions, or owner intent.
- Weak/unverified evidence is repaired or internally rejected instead of being delegated to the user.
- Added cross-component consistency rule for SEO title, H1, meta, introduction, headings, FAQ, and body promises.
- A real user decision must ask a concrete YES/NO or named-option question and must be finalized before SBM registration.
