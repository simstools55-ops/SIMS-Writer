# Official Regression Suite v1

このディレクトリは今回の5記事を固定保存するための受け皿です。

各ケースには最終的に次を保存します。

- `input.md`: SBMから渡された元の依頼文
- `original-output.md`: Writerが当時出した未修正回答
- `expected-qa.json`: QAが検出すべき問題と初回判定
- `expected-final.md`: 自動修正可能な場合の公開版
- `notes.md`: テスト目的と変更禁止事項

`input.md`と`original-output.md`は固定後に修正しません。元資料がまだリポジトリにないため、現在はmanifestのみ登録しています。
