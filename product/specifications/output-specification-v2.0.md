# Output Specification v2.1

表示順は次で固定する。

1. 公開可否を示す一文
2. `SERP比較結果`（SERPが修正判断の根拠になった場合のみ）
3. `公開OK`
4. `利用者判断`（該当時のみ）
5. 内部リンク結果（必要時のみ一文）
6. Contract 4.1 JSON

冒頭の一文は、利用者判断がなければ「今回の修正は、そのまま公開できます。」、利用者判断があれば「公開OKの修正はそのまま反映できます。利用者判断の項目だけ確認してください。」とする。

SERP比較結果は、`現在の記事の強み`、`不足していた点`、`今回補う点`、`今回は補わない点`を短く示す。競合URL一覧、内部スコア、Evidence階層、Validationは表示しない。比較件数・掲載率を推測しない。

公開OKは完成したBefore/Afterを持つ。説明が必要な場合も、読者にとって何が分かりやすく・正確に・安全になるかを平易な一文で示す。

利用者判断はBefore/After、判断理由、採用時の利点、不採用時の影響、確認事項を持つ。内部却下案と内部品質指標は表示しない。

内部リンク候補が全件不採用なら「今回は追加できる内部リンクはありません。」の一文だけを表示する。
