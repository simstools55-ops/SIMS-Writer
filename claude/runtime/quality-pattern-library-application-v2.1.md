# Quality Pattern Library Application v2.1

Before creating a new product rule, consult `shared/quality/QUALITY_PATTERN_LIBRARY.md`.
Classify every operational-test finding as ARTICLE_SPECIFIC, PATTERN_CANDIDATE, MAPPING_DEFECT, VALIDATION_DEFECT, or PREFERENCE_ONLY.
A repeated defect with an existing canonical rule is not a new pattern; fix the product mapping, runtime connection, or final validation.
