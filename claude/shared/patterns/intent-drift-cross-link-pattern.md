# Intent Drift Detection and Cross-Link Routing Pattern

## Pattern ID

W-INTENT-DRIFT-001

## Status

PATTERN_CANDIDATE — promote to mandatory runtime behavior after a second independent real-article confirmation.

## Trigger

A high-impression query or query cluster has a materially different search intent from the article's primary purpose.

## Required conditions

- the current article adequately serves its primary intent;
- a winning query or established title asset should be preserved;
- another site article clearly serves the drifting intent;
- routing can be added without expanding the current page into a second topic.

## Action

1. Explain the distinction early in the introduction when confusion is likely.
2. Link to the page that serves the alternate intent.
3. Add a comparison FAQ only when it helps readers self-select.
4. Preserve the current title and metadata unless the page itself should be realigned.
5. Record the alternate query as separate intent, not as evidence that the current page should absorb it.

## Do not apply when

- the high-impression query is actually the page's primary intent;
- no validated destination article exists;
- page roles are unclear or cannibalization risk is unresolved;
- the current page is demonstrably the wrong page and requires strategic realignment.

## First evidence instance

A000081: Instagram “login history” queries represented security login activity, while the article served online-status and last-active visibility. The safe solution was distinction plus cross-linking, not title realignment.
