# Dynamic Claim Safe Rewrite Pattern

## Use when

価格、送料、割引、期間、アプリ仕様、UI、提供条件を現在の一次情報で確認できないとき。

## Unsafe

- 公式サイトが最安値
- 数日から数週間で戻ることが多い
- この機能は存在しない

## Safe transformation

- 現在の価格・キャンペーンを公式サイトで確認してください
- 一時的な仕様変更や不具合の可能性もあるため公式案内を確認してください
- 利用環境やバージョンで異なるため、現在の公式設定案内を確認してください

具体的主張を曖昧な断定へ置換せず、確認行動を明示する。
