# Learning Registry Validation

## VAL-LEARNING-001 Classification
すべての実記事Learningが5分類のいずれか1つを持つこと。

## VAL-LEARNING-002 Existing Rule Check
PATTERN_CANDIDATEを新規採用する前にQuality Pattern Libraryとの重複確認があること。

## VAL-LEARNING-003 Delivery Path
ACCEPTEDまたはIMPLEMENTEDの共通ルールが、対象製品のScoped SnapshotとRuntimeへ到達していること。

## VAL-LEARNING-004 Regression Fixture
MAPPING_DEFECTとVALIDATION_DEFECTには再発ケースを固定した回帰テストがあること。

## VAL-LEARNING-005 Closure
VERIFIED/CLOSEDには変更ファイルとテスト結果が記録されていること。

## VAL-LEARNING-006 No Preference Promotion
PREFERENCE_ONLYをQuality Patternへ昇格させないこと。
