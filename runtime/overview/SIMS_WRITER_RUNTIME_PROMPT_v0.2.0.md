

## v3.0 knowledge-driven temporal architecture

After knowledge assembly and before content planning, run Temporal Lifecycle Analysis whenever the subject includes dates, launches, campaigns, benefits, deadlines, active services, distribution, expiration, annual versions, prices, requirements, or future-tense placeholders. Then run contradiction and preservation audits. Use Shared v3 confidence/source/review policies. Keep `SIMS_FEEDBACK_V2` and `publication_result` backward compatible; optional v3 analysis fields must never replace required v4.2 fields.
