# Integrated Gap Analysis v2.0

A content gap is valid only after combining three inputs:

1. Search Console: proves that some users reached the article through a query.
2. Verified SERP: shows how the current result set interprets and answers the query.
3. Evidence Layer: determines whether the proposed answer can be stated safely and accurately.

A query row alone is an investigation lead, not an authorization to add content.
A recurring SERP topic without reliable evidence is not PUBLIC_OK.
A reliable first-party fact that is absent from competitors may still be valuable and should not be discarded merely because it is uncommon.

Gap classifications:
- `SUPPORTED_GAP`: query/SERP relevance plus sufficient evidence; eligible for planning.
- `DECISION_GAP`: relevant but evidence is incomplete; Writer must verify, repair, or hold internally. It is not user homework.
- `UNSUPPORTED_GAP`: plausible but unsupported; INTERNAL_REJECT.
- `NO_GAP`: already answered adequately.
- `SEPARATE_INTENT`: better handled by another article.
