# SERP Gap Report v2.0

SERP Gap Reportは、修正案の前に利用者へ示す短い比較要約である。診断レポートではない。

表示する内容:
- 現在の記事で十分に扱えている強み
- 検索意図上重要で不足または弱かった点
- 今回補う点
- 今回補わない点と簡潔な理由

採用条件:
1. SERPを実際に確認している。
2. Search Console需要、SERP傾向、自記事本文の三者を照合している。
3. 「競合にあるから」だけで不足認定しない。
4. 比較件数・掲載率は確認済みの実数だけを書き、推測値を作らない。
5. Evidence不足の事実はGapとして発見できても、公開OKへの採用はEvidence Layerに従う。

利用者向け表示は最大6項目程度とし、競合URL一覧、内部スコア、詳細な順位表は表示しない。
