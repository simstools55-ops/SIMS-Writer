# SERP-first Editorial Planning

When a target page is not within the top three for its main query, inspect the current top results before deciding the editorial change scope. This is a blocking evidence gate for search-intent, competitor-gap, heading, FAQ, body, structure and title-promise edits.

Use the results to understand the search intent, expected answer form and material coverage—not as text or outline templates. Compare the target article against common intent-material coverage, weak or missing material, useful original value, and accuracy/freshness differences.

If current result-page evidence is only partial or unavailable, Search Console query rows cannot substitute for it. Do not approve new FAQs, heading changes, body expansion, structural edits or competitor-gap claims. Permit only mechanical or independently verified factual corrections that do not depend on current SERP intent.

Only add a gap when it is relevant to the searcher's task and can be supported. Never manufacture findings from snippets or unavailable pages. A response must never both admit that current top pages were unverified and present SERP-dependent edits as publishable.
