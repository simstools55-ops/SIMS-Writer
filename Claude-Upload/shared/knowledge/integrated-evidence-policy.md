# Integrated Evidence Policy

## Purpose

SIMS Editorial Platformにおける診断・編集判断は、単独Evidenceではなく、相互に独立した複数Evidenceの整合性・矛盾・鮮度・信頼度を統合して行う。

## Principle

Evidenceは観測事実または根拠であり、DiagnosisやTreatment Strategyそのものではない。

```text
Evidence sources
    -> confidence / freshness / contradiction review
    -> integrated evidence assessment
    -> diagnosis or editorial decision
```

## Integration rules

1. 強い単独Evidenceでも、反証可能な別Evidenceが利用可能なら確認する。
2. Search Consoleの需要・順位変化は事実性の証拠として扱わない。
3. SERP観測は検索意図・競合環境の証拠であり、記事内の事実主張を直接証明しない。
4. 公式・一次情報は対象主張のsource authorityを高めるが、対象期間・scopeが一致していることを確認する。
5. サンプル不足、古いデータ、矛盾、欠損Evidenceはconfidenceを下げる。
6. Evidence間で結論が異なる場合は、都合の良い一方を捨てず、複合診断・保留・再検査として表現する。
7. 外部環境Evidence（Algorithm Update、季節性、制度変更等）は、記事固有Evidenceと統合して評価する。

## Confidence

Confidenceの詳細は既存の `evidence/source-confidence-freshness.md` と `knowledge/evidence-confidence-and-contradiction.md` を正本とする。本Policyは新しい重複スコア体系を定義しない。

## Output wording

Evidenceが弱い場合は「可能性」「示唆」「未評価」を用い、強い因果表現を避ける。複数の独立Evidenceが一致しても、観測研究的なSEO診断では必要以上に原因を断定しない。
