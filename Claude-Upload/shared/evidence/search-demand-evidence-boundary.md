# Search Demand and Factual Evidence Boundary

Search Consoleクエリは需要・表記ゆれ・質問候補を示すが、事実の証明にはならない。

## Permitted uses

- 検索需要の把握
- 表記ゆれ・別名の発見
- FAQ候補の抽出
- 検索意図仮説の作成

## Prohibited substitutions

Search Console需要を、次の確認の代替にしてはならない。

- 製品・OS・アプリの機能仕様
- 価格、送料、割引、定期条件
- 運賃、時刻、乗り場
- 学費、制度、資格要件
- 医療、食品安全、健康効果
- 超自然的原因の因果説明

変動情報は公式または一次情報で現在性を確認し、確認できない場合は具体値・断定を削除して公式確認案内へ変更する。
