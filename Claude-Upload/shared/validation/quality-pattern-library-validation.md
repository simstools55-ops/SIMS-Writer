# Quality Pattern Library Validation

- VAL-QPL-REGISTRY-001: Registryにある全Canonical sourceが存在する。
- VAL-QPL-MAPPING-001: Writer MappingがQuality Pattern Libraryを必須参照する。
- VAL-QPL-PROMOTION-001: 新ルール追加時にPromotion classificationと回帰テストがある。
- VAL-QPL-NO-DUPLICATE-001: 同じ規則をKnowledge/Patternへ重複コピーせず正本を一つにする。
- VAL-QPL-NO-LOOP-001: 再発時は個別修正ではなくMapping/Validation defectとして処理する。
